### Problem Analizi (Root Cause)

Photo Editor plugin kodunu detaylı inceledik ve kritik farkı bulduk:

1. **Photo Editor'un Modern Yaklaşımı:**
   - `bNewVersion = true` durumunda `executeMethod("PutImageDataToSelection", [oImageData])` kullanıyor
   - Bu API metodu yeni versiyon OnlyOffice'te en güvenilir yol

2. **Eski Yaklaşım (Bizim Hatamız):**
   - `callCommand` + `Api.CreateImage` + `InsertContent` eski versiyon için
   - `callCommand` içinde data URL sessizce başarısız oluyordu

### Uygulanan Düzeltmeler:

1. **`PutImageDataToSelection` API'sine Geçiş**
   - Photo Editor'un modern yaklaşımı benimsendi
   - `executeMethod("PutImageDataToSelection", [oImageData])` kullanılıyor
   - Data URL doğrudan destekleniyor

2. **Gerçek Boyut Hesaplama**
   - PNG export sonrası `Image()` ile gerçek boyutlar alınıyor
   - Max 800px genişlik sınırı (orantılı küçültme)

3. **Re-edit için LocalStorage**
   - mxfile XML'i localStorage'a kaydediliyor
   - Resim hash'i ile eşleştirme yapılıyor
   - Seçili resim varsa `GetImageDataFromSelection` ile alınıyor

4. **Daha İyi Hata Yönetimi**
   - Image load başarısız olursa fallback boyutlar (600x400)
